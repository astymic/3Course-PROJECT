## 🔄 Фаза Planning — ПОТОЧНИЙ ТИЖДЕНЬ

### 1. WBS (Work Breakdown Structure)
- Ієрархічне розбиття всього продукту MVP на складові.
- Приклад структури:
  ```
  1.0 Каталог товарів
    1.1 Фільтрування
      1.1.1 Фільтр за розміром
      1.1.2 Фільтр за кольором
      1.1.3 Фільтр за ціною
      1.1.4 Фільтр за категорією (літнє/зимове)
    1.2 Картка товару
      1.2.1 Фото з усіх ракурсів
      1.2.2 Розмірна сітка
      1.2.3 Відображення наявності по розмірах
  2.0 Кошик та замовлення
    2.1 Додавання / видалення товару
    2.2 Оформлення замовлення
  3.0 Оплата
    3.1 Онлайн-оплата карткою
    3.2 Накладений платіж
  4.0 Доставка
    4.1 Нова Пошта
    4.2 Кур'єр
  5.0 Popup-консультація
  6.0 Адмін-панель
    6.1 Управління товарами
    6.2 Управління замовленнями
    6.3 Облік складу
  7.0 Інфраструктура
    7.1 Домен
    7.2 Хостинг
  ```
- Це стане базою для Gantt-діаграми PM (Руслана).

### 2. Product Backlog & User Stories
- Описати функціонал у форматі: *«Як <тип користувача>, я хочу <дія>, щоб <цінність>»*.
- Пріоритезувати: Must have → Should have → Could have.
- Обов'язково врахувати специфіку фабрики «LiLu»:
  - 🔹 Таблиця розмірів
  - 🔹 Відображення наявності по КОЖНОМУ розміру (ключова вимога Наталії!)
  - 🔹 Фото з усіх ракурсів (щоб не питали в Instagram)
  - 🔹 Категорії: літнє/зимове взуття
  - 🔹 Popup для зв'язку з менеджером

### 3. Quality Management Plan
- Описати, як команда гарантує якість документів та прототипу:
  - Перехресне рев'ю артефактів.
  - Чеклісти перевірки.
  - Відповідність кожної фічі User Stories.

### 4. Project Lifecycle Visualization
- Оформити як офіційний артефакт Planning.
- Показати повний цикл Scrum: Initiation → Planning → Sprint 1 → Sprint 2 → Sprint 3 → Closure.
- Обґрунтувати вибір Adaptive/Scrum (вимоги уточнюються, MVP, маленька команда).

## 💡 Пам'ятка
- Наталія сказала дослівно: *«Щоб відображалася наявність товару на складі... якщо 37 розміру немає, щоб це відображалося на сайті»*. Це — ваш Must Have #1.
- Конструктор взуття — Фаза 2. Не включайте його в Backlog MVP.
- WBS потрібно здати першим — від нього залежить Gantt у Руслана та Jira у Максима.
