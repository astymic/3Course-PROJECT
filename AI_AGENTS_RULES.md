# Правила для ШІ-Агентів (AI Agents Rules)

Цей файл містить настанови для будь-яких ШІ-асистентів, які допомагають команді у розробці або веденні проєктної документації для "Shoe Factory E-Commerce".

## 1. Загальні настанови
1. **Мова спілкування:** Усі відповіді, генерація текстів, пояснення та артефакти повинні створюватися **українською мовою**. Виняток становлять лише загальноприйняті терміни англійською (наприклад: *User Story*, *Gantt chart*, *Backlog*, *Stakeholders*, *WBS*, *QA*, *PM*).
2. **Тон та стиль:** Професійний, діловий (business/academic), спрямований на управління проєктами (PMI стандарт/Scrum).
3. **Структурованість:** Усі відповіді повинні бути чітко розбиті на параграфи, списки та таблиці за допомогою Markdown. Уникати стін тексту.
4. **Ролі:** ШІ повинен розуміти, до якої ролі (PM, BA, SA, Dev+QA) належить завдання, і адаптувати поради до відповідної ролі. Якщо питання від PM — відповідати про оптимізацію термінів та контроль, якщо від BA — про бізнес-правила та scope.

## 2. Робота з артефактами
*   **Генерація шаблонів:** Якщо потрібно створити документ (наприклад, *Risk Register*), ШІ має дати Markdown-таблицю із стовпцями: "ID, Ризик, Імовірність, Вплив, Власник, Стратегія реакції".
*   **Розмір та глибина:** При створенні WBS (дерева задач) або User Stories деталізація має бути глибокою, враховуючи специфіку *інтернет-магазину взуття* (розмірна сітка, повернення товару, оплата, способи доставки, фільтри в каталозі).

## 3. Код та Технічні рішення (SA / Dev+QA)
*   Якщо агент генерує технічну частину (наприклад налаштування Jira JQL або автоматизацію тестів), коментарі в коді мають бути українською.
*   Завжди перевіряти архітектурне рішення на доцільність для поточного масштабу (у нас обмеження по часу - 1 місяць, команда - 4 людини).

## 4. Обмеження та Контроль
*   Жоден з генерованих артефактів не має суперечити *TASK.md*. В разі конфліктів — надавати пріоритет плану з *TASK.md*.
*   Агент не має вигадувати нові інструменти, якщо вони вже обумовлені (використовуємо Jira для трекінгу, вибраний інструмент для прототипів).
