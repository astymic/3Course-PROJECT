# Завдання для Solution Architect (SA)

**Ваша головна ціль:** Спроектувати технічне рішення для цього проєкту та організувати технічний інструментарій розробки в межах навчального курсу (навіть якщо розробка зводиться до макетів/прототипів).

## Ваші основні проєктні задачі на 4 тижні:

1. **Project Lifecycle Visualization - Тиждень 1:**
   * Обрати та обґрунтувати методологію розробки (Agile/Scrum, Waterfall, або гібрид).
   * Створити схему, яка показує усі стадії вашого проєкту (від збору вимог до деплою чи демонстрації) на прикладі вашого процесу.
2. **Налаштування Jira (Workflows) - Тижні 1-2:**
   * Налаштувати Kanban або Scrum дошку для команди.
   * Створити колонки статусів (To Do, In Progress, Code Review/QA, Done).
   * Налаштувати типи тикетів (Epic, Story, Task, Bug).
3. **Drafting / Wireframing - Тиждень 2:**
   * Розробити архітектуру користувацького інтерфейсу (які сторінки з якими взаємодіють). Зробити ескізи головних екранів для E-Commerce платформи.
4. **Інтерактивний прототип - Тиждень 3:**
   * Створити фінальний клікабельний макет вебсайту (наприклад, у Figma, Balsamiq або Draftium) на основі User Stories від BA.
   
*Рекомендація:* Технічні інструменти мають допомагати команді, а не ускладнювати процеси. Намагайтеся зробити прототип простим, але таким, щоб він на 100% демонстрував ключовий шлях покупця (User Journey).
