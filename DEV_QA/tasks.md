## 🔄 Фаза Planning — ПОТОЧНИЙ ТИЖДЕНЬ

### 1. Архітектурна схема системи (перейшла від SA)
- Визначити технічний стек для MVP інтернет-магазину.
- Намалювати архітектурну діаграму (frontend, backend, база даних, інтеграції).
- Врахувати:
  - Облік складу в реальному часі по кожному розміру.
  - Інтеграція з Новою Поштою (API).
  - Платіжний шлюз (LiqPay, Fondy або аналог).
  - Popup-консультація (чат-віджет або кастомне рішення).
- **Архітектура повинна передбачати додавання конструктора взуття у Фазі 2** без повної переробки.

### 2. Cost Baseline
- Прорахувати вартість запуску та утримання сайту:
  - Домен (.ua або .com.ua) — орієнтовна ціна.
  - Хостинг (VPS, shared або cloud) — щомісячна вартість.
  - SSL-сертифікат.
  - Платіжний шлюз — комісії.
  - Інструменти розробки (Figma, Jira — безкоштовні версії).
- Наталія просила: *«Прорахуйте, скільки коштів піде на цей сайт»*.

### 3. Налаштування Jira Workflow
- Створити дошку (Scrum Board) для команди.
- Колонки: To Do → In Progress → Review → Done.
- Типи тикетів: Epic, Story, Task, Bug.
- Наповнити задачами **після** отримання User Stories від BA (Ілля).
- Призначити задачі Sprint 1 на відповідних учасників.

## ⏳ Фаза Execution (Тижні 3–8)

### 4. Інтерактивний прототип
- Створити клікабельний прототип вебсайту (Figma, Draftium, або кодом).
- Ключовий User Journey: каталог → картка товару → перевірка розміру → кошик → оформлення → оплата.
- Окремо: адмін-панель для менеджерів.

### 5. QA Check-list та тестування
- Написати конкретні Test Cases для кожної фічі MVP:
  - «Фільтр за розміром показує тільки товари з наявним 38 розміром»
  - «Кнопка "Купити" додає товар у кошик»
  - «Розмір, якого немає на складі, відображається як недоступний»
  - «Popup консультації відкривається при натисканні»
- Тестувати прототип і заводити баги у Jira.

### 6. Lessons Learned / Post-mortem (Closure)
- Зібрати від команди відповіді:
  - Що спрацювало добре?
  - Що було погано?
  - Що б змінили наступного разу?
- Зафіксувати відхід Альони як спрацьований ризик і описати як команда впоралася.
- Оформити як єдиний документ.
