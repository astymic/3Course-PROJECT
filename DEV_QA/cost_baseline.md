## 5. Зведення: загальна вартість запуску MVP

| Категорія | Одноразово | Щомісяця |
|---|---:|---:|
| Домен (1 рік) | ~250 грн | — |
| Хостинг (free tiers) | 0 | 0 – 371 грн |
| Інструменти | 0 | 0 |
| Зовнішні сервіси | 0 | 2.75% від продажів |
| Людські ресурси (навч.) | 0 (навчальний) | — |
| **РАЗОМ** | **~250 грн** | **0 – 371 грн** |

### Висновок для клієнта:
> **Запуск MVP обійдеться від ~250 грн (домен)** при використанні безкоштовних планів хостингу. Щомісячна підтримка на етапі старту — **до 371 грн/міс**. При масштабуванні (зростання трафіку або потреба в конструкторі) вартість зросте, але це буде Фаза 2.
>
> **Час до запуску:  2 місяці** (8 тижнів від старту, включаючи документацію та 3 спринти розробки).
